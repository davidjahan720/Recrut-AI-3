# Tutoriels

> **Apprendre en faisant.** Pas-à-pas, on tient la main, le résultat est garanti.

À distinguer des **how-to** (`/docs/how-to/`) qui supposent que l'on sait déjà ce qu'on fait et qu'on cherche juste la recette d'une tâche précise.

## Convention

- Frontmatter `type: tutorial`.
- Numéroter `01-`, `02-`... dans l'ordre logique d'apprentissage.
- À la fin, lister 2-3 prochaines étapes (lien vers how-to ou explanation).
- Chaque étape doit être **vérifiable** par l'utilisateur (commande à exécuter, résultat attendu).
